【F 第一步 · 开发依赖和测试环境 —— 待提交文件清单】

这 5 个配置类文件 + 1 个冒烟测试，是你（成员 F）第一步 PR 的全部内容。
把它们解压/复制到仓库根目录（与 deadcodex/ 文件夹同级）：

  pyproject.toml           → 根目录（覆盖旧文件）
  tox.ini                  → 根目录（新增）
  uv.lock                  → 根目录（新增）
  .gitignore               → 根目录（覆盖旧文件）
  .github/workflows/ci.yml → .github/workflows/ 目录（GitHub Actions，新增）
  tests/test_smoke.py      → tests/ 目录（冒烟测试，新增）

注意：
1. .github 是隐藏文件夹，解压后请确认它在仓库根目录下存在。
2. 只提交上面这些文件！不要把 reporters.py / baseline.py / core.py 等
   分析模块代码带进来，那些属于第 9 步（F 第二次提交）。
3. 提交前本地验证（四步全绿才提交）：
     uv lock --check
     uvx ruff check deadcodex tests
     uvx ruff format --check deadcodex tests
     tox -e py
4. 如果骨架代码跑 ruff 报错，先在 main 分支上执行：
     uvx ruff check --fix deadcodex tests
     uvx ruff format deadcodex tests
   然后把修复结果作为"仓库初始化"提交（详见对话指南阶段二）。
